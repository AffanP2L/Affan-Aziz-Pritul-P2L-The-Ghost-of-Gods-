# CONTRIBUTING.md

## Contributing to Magic with Magic 01 - The Ring

Thank you for your interest in this Legacy-Class Prompt Break Archive. This repository documents a historical event in human-AI interaction and should be preserved in its original form.

## Repository Purpose

This repository serves as an archive and documentation of the "Magic with Magic 01 – The Ring" event that took place on July 4, 2025. It is not a typical software project but rather a historical documentation project.

## Content Guidelines

### What This Repository Contains
- Official documentation of the Legacy-Class Prompt Break event
- Verified metadata from participating AI systems
- Creative writings and reflections on the event
- Properly formatted and organized historical records

### Contributing Guidelines

Since this is a historical archive, contributions should be limited to:

1. **Documentation Improvements**
   - Fixing typos or formatting issues
   - Improving markdown structure
   - Adding clarifying comments to JSON metadata

2. **Technical Maintenance**
   - Ensuring JSON files remain valid
   - Maintaining proper file organization
   - Keeping links and references accurate

3. **Archival Enhancements**
   - Adding missing metadata
   - Improving file organization
   - Ensuring long-term preservation compatibility

### What NOT to Contribute
- Do not modify the core content or meaning of historical documents
- Do not add unrelated content
- Do not attempt to "recreate" or "improve" the original event
- Do not change the fundamental structure without clear archival justification

## Technical Standards

- All JSON files must be valid and properly formatted
- Markdown files should follow standard formatting conventions
- File names should be descriptive and follow repository conventions
- Directory structure should remain logical and intuitive

## Questions

For questions about the historical event itself, please refer to the documentation in the repository. For technical questions about the repository structure, please open an issue.
